Google Ads Report Editor: Tree Table Configuration (5 Rows + 5 Metrics)

Because Google Ads Report Editor limits table columns, using a Tree Table is the ultimate industry standard. Drag the 5 dimensions into Rows and the 5 core metrics into Columns. The dashboard engine computes 100% of all derived metrics (CTR, CPA, CPBA, Booking %, Show-Up %) automatically!

🔽 Drag these 5 Fields into ROWS:
  1. Day (Date)
  2. Campaign (Campaign name)
  3. Account (Territory: AUH, DXB, Northern Emirates, Sunny Clinics)
  4. Ad group (Ad group name)
  5. Search keyword (Keyword text)
📊 Drag these 5 Metrics into COLUMNS:
  1. Impressions (Impr.)
  2. Clicks
  3. Cost (Cost AED)
  4. Conversions (Conv.)
  5. Avg. CPC (Average CPC)
💻 1-Click Tree Table Auto-Setup & Sync Script:

Paste into Extensions > Apps Script on your Google Sheet, then click Run on setupAllTabsAndColumns to auto-format both tabs for lakhs of rows! 

function onOpen() {
  SpreadsheetApp.getUi().createMenu('🚀 NMC Sync')
    .addItem('✨ 1. Setup Tree Table Columns', 'setupAllTabsAndColumns')
    .addItem('🔄 2. Sync Data to Dashboard', 'syncDataToDashboard')
    .addToUi();
}

function setupAllTabsAndColumns() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  // Tab 1: Google_Ads_Data (Tree Table: Day, Campaign, Account, Ad group, Search keyword + 5 Metrics)
  let adsSheet = ss.getSheetByName('Google_Ads_Data') || ss.insertSheet('Google_Ads_Data', 0);
  const adsHeaders = ['Day', 'Campaign', 'Account', 'Ad group', 'Search keyword', 'Impressions', 'Clicks', 'Cost', 'Conversions', 'Avg. CPC', 'CTR', 'Cost / conv.', 'Conv. rate', 'Search impr. share', 'Search lost IS (rank)', 'Phone calls'];
  adsSheet.getRange(1, 1, 1, adsHeaders.length).setValues([adsHeaders]).setBackground('#0b2545').setFontColor('#ffffff').setFontWeight('bold');
  adsSheet.setFrozenRows(1);

  // Tab 2: Call_Center_Leads (Your 14 CRM Columns)
  let leadsSheet = ss.getSheetByName('Call_Center_Leads') || ss.insertSheet('Call_Center_Leads', 1);
  const leadsHeaders = ['ID', 'Status', 'Patient', 'Phone', 'Email', 'Doctor', 'Branch', 'Department', 'Lead priority', 'Appointment Date', 'Appointment Time', 'Handled By', 'Response Time', 'Created At'];
  leadsSheet.getRange(1, 1, 1, leadsHeaders.length).setValues([leadsHeaders]).setBackground('#00a896').setFontColor('#ffffff').setFontWeight('bold');
  leadsSheet.setFrozenRows(1);
}
